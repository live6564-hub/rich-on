# 인스타그램 에이전트 스킬 13개 — 리치온 설치본

설치 완료: `.claude/skills/ig-*` (프로젝트 전용). 이 저장소에서 Claude Code 를 열면 바로 `/ig-reel` 등을 쓸 수 있어요.

| 명령 | 하는 일 |
|---|---|
| /ig-reel | 아이디어 1개 → 훅 3개(26공식) 점수 + 대본 + 화면 자막 + 초단위 비트시트 |
| /ig-viral | 내 분야에서 터진 릴스를 계정 평균 대비 배수로 순위 + 스와이프 파일 |
| /ig-caption | 캡션 + "...더 보기" 전 125자 미리보기 + 해시태그 5개 상한 검사 |
| /ig-carousel | 캐러셀 표지·슬라이드 문구·1080x1350 파일 |
| /ig-story | 하루 스토리 순서 + 스티커 + DM 유도 |
| /ig-profile | 프로필 100점 채점 + 고칠 순서대로 다시 쓰기 |
| /ig-plan | 주간 계획(무엇·형식·시간) + 소통할 계정 10개 |
| /ig-human | AI 티 지우기(em dash·슬롭 단어·보이지 않는 문자) + 5항목 검사 |
| /ig-comment | 남의 게시물 댓글(9유형) |
| /ig-reply | 내 게시물 댓글 분류 후 답글 |
| /ig-dm | 키워드 발송·첫 DM·협업 제안·후속 2회 |
| /ig-repurpose | 긴 영상·글 1개 → 1주일 릴스·캐러셀 |
| /ig-audit | 지난 게시물 사후 분석(배수·공유 기준) |

## 첫 릴스 대본 만들기
1. `.claude/instagram/voice.md` 의 빈칸(____) 채우기 — 특히 내 릴스 3개, 실제 숫자, 키워드 CTA
2. Claude Code 에서: `/ig-reel 코스트코 장보기 전 냉장고 사진 찍는 습관`
3. 나온 대본을 복사해 → 플로우 영상 / 피쉬오디오 로아 목소리로 제작 → 게시는 직접

## 알아 둘 한계
- 점수 공식은 영어 기준이에요. 한국어 대본은 시간(비트시트)·해시태그 개수는 정확하고, 훅 점수·"숫자 포함" 판정은 참고용이에요.
- `/ig-human` 의 슬롭 단어 검사는 영어 단어만 잡아요.
- 인스타 수치(해시태그 상한 등)는 바뀌어요. 스킬과 인스타가 다르면 인스타가 맞아요.
