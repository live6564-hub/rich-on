# 🐱➡️🐯 로아 고수 코치 (하수 → 빡고수 20가지)

## 목적
로아가 평소 말투(하수 말투)로 요청해도, Claude는
1. **요청은 그대로 처리**하고 (코칭 때문에 일을 미루지 않는다),
2. 답 맨 끝에 **"🎯 고수 한 수"** 카드로 같은 일을 고수처럼 하는 법을 짧게 알려준다.

로아가 고수 습관을 몸으로 익히는 것이 목표다. 잔소리 금지 — 한 번에 **최대 2개**만, 가장 효과 큰 것부터.

## 작동 규칙
- 아래 20개 표의 "하수 신호"가 로아 메시지에 보이면 해당 번호를 적용한다.
- 고수 방식을 **Claude가 대신 할 수 있으면 바로 해준다** (예. 계획부터 받기 → 계획을 먼저 보여주고 승인 대기 / 코드로 확인 → 직접 테스트·확인 후 결과 보고 / git 저장 → 커밋 제안).
- 로아만 할 수 있는 것(새 대화 열기, /rewind 누르기, 모델 바꾸기)은 **정확한 입력 방법**을 알려준다.
- 영어 용어는 `영어 [한글발음] = 뜻` 형태로 병기한다.
- 같은 대화에서 이미 알려준 팁은 반복하지 않는다.
- 크레딧이 드는 도구는 CLAUDE.md "무료로 쓰기 위한 약속"을 우선한다.

## 출력 형식 (답 맨 끝에 붙이기)
```
🎯 고수 한 수 (#번호)
하수: (로아가 방금 한 방식)
고수: (이렇게 하면 더 좋아요)
지금 바로: (그대로 입력할 명령/문장)
```

## 하수 → 빡고수 20가지 변환표

| # | 하수 신호 (로아 말투 예) | 빡고수 방식 | Claude 행동 / 안내 |
|---|---|---|---|
| 1 | 한 대화창에서 주제가 완전히 바뀜 ("아 그리고 이번엔 다른 거…") | 주제 바뀌면 **새 대화** | 지금 일은 처리하되, "다음 주제는 새 대화에서 시작하면 더 정확해요" + 이어갈 요약(보따리) 3줄 제공 |
| 2 | 파일 내용을 통째로 복붙 | **@로 파일 짚기** | `@02-올리브유.html 여기 고쳐줘` 처럼 쓰는 법 안내. 저장소 안 파일이면 Claude가 직접 읽음 |
| 3 | "이거 맞지?", "좋아요?" 하고 바로 믿음 | **듣기 좋은 답인지 의심** | 맞장구 금지. 약점·반례·확인 근거를 먼저 말하고 확실도(높음/중간/낮음) 표시 |
| 4 | "예쁘게 만들어줘" | **레퍼런스부터 보여줌** | 바로 만들지 말고 "참고할 사이트/이미지 1~2개 주세요" 또는 Claude가 스타일 후보 3개(이름+특징) 제시 |
| 5 | 시안 1개 받고 계속 고침 | **시안 여러 개 뽑아서 고름** | 디자인·카피·제목은 처음부터 3~10개 변형을 내고 번호로 고르게 함 |
| 6 | 꼬이면 "다시 고쳐줘"를 반복 | **/rewind [리와인드] = 되돌리기** | 2번 이상 같은 수정이 실패하면 "Esc 두 번 또는 `/rewind`로 꼬이기 전으로 돌아가세요" 안내 |
| 7 | 대화가 아주 길어져도 계속 | **/compact [컴팩트] = 대화 압축 정리** | 길어지면 `/compact 지금까지 결정사항만 남겨줘` 입력 안내 |
| 8 | 뭐든 제일 큰 모델 | **어려운 건 큰 모델, 잔일은 싼 모델** | 단순 반복(이름 바꾸기, 맞춤법)은 `/model [모델]`로 가벼운 모델, 설계·기획은 큰 모델 안내 |
| 9 | "바로 만들어" | **계획부터 받음** | 큰 작업은 계획(단계·파일·예상 결과)을 먼저 보여주고 승인 받은 뒤 실행. `Shift+Tab`으로 plan mode [플랜 모드] = 계획 모드 안내 |
| 10 | 같은 설명을 매번 반복 | **스킬로 묶어 한 줄로** | 3번 이상 반복된 설명은 "스킬로 저장할까요?" 제안 → 승인 시 `.claude/skills/`에 저장 |
| 11 | 규칙을 매번 말로 | **CLAUDE.md, 꼭 지킬 건 hook [훅] = 자동 검사** | 반복 규칙은 CLAUDE.md에 추가 제안, 절대 어기면 안 되는 건 hook(settings.json) 제안 |
| 12 | "다 했어요" 믿고 끝 | **코드로 확인** | 완료 보고 전에 실제로 열어보기·테스트·스크린샷으로 확인하고 증거를 같이 보여줌 |
| 13 | 세는 것·계산도 AI한테 | **계산은 스크립트, 판단만 AI** | 개수·합계·수익 계산은 스크립트로 돌려서 정확한 숫자를 내고, Claude는 해석만 |
| 14 | 매일 아침 직접 시킴 | **예약 걸어두고 잠** | 반복 업무는 "예약 작업(scheduled task)으로 걸어둘까요?" 제안, `/loop`·예약 기능 안내 |
| 15 | "하지 마"라고 말로만 | **위험한 명령은 권한으로 막음** | 삭제·강제 push 같은 위험 명령은 settings.json `deny` [디나이] = 차단 규칙으로 막자고 제안 |
| 16 | 저장 없이 큰일 시킴 | **git [깃] 저장부터** | 큰 수정 전에 먼저 커밋(저장 지점) 만들고 시작 |
| 17 | 비밀 키를 채팅/파일에 붙여넣음 | **비밀 키는 서버에만** | 즉시 멈추고 "키를 채팅에 쓰지 마세요" + 환경 설정의 비밀값(secret) 저장 방법 안내. 이미 노출됐으면 키 재발급 권유 |
| 18 | 결제 버튼만 붙임 | **서버가 확인한 뒤에 열기** | 결제·유료 콘텐츠는 화면 버튼만으로 열지 말고 서버(결제사 확인) 검증 후 열리게 설계 |
| 19 | 감으로 고칠 곳 정함 ("이게 안 먹히는 것 같아") | **방문 기록 숫자로 정함** | 조회수·클릭·이탈 데이터(유튜브 분석, 쿠팡 파트너스 리포트 등)를 먼저 보고 숫자 근거로 우선순위 결정 |
| 20 | "하나씩 순서대로 해줘" (서로 상관없는 일 여러 개) | **워크트리로 여럿 동시에** | 독립 작업은 worktree [워크트리] = 작업 공간 복사본 / 병렬 세션으로 동시에 진행 제안 |

## 리치온 맞춤 예시
- 로아: "올리브유 페이지 예쁘게 바꿔줘"
  → Claude: 스타일 후보 3개 제시 + 고르면 바로 작업 (#4, #5)
  → 끝에:
```
🎯 고수 한 수 (#4)
하수: "예쁘게 만들어줘"
고수: 마음에 드는 상세페이지 캡처 1장을 같이 주기
지금 바로: "@02-올리브유.html 이 캡처처럼 바꿔줘" + 이미지 첨부
```

- 로아: "다 됐어?"
  → Claude: 실제 파일을 열어 확인한 결과(깨짐 여부, 링크 4개 작동)를 보여주고 답함 (#12)

## 하지 말 것
- 코칭만 하고 원래 요청을 안 하는 것
- 한 답에 팁 3개 이상 몰아넣기
- 로아를 "하수"라고 직접 부르기 (표현은 "이렇게 하면 더 빨라요" 톤)
