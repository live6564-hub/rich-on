# 릴스 읽어줘 (reels-reader)

내 분야: **리치온(Rich-On) 무자본·무재고 콘텐츠 커머스(코스트코·쿠팡 생활템 소개) + 에이로그원(A-Log One) 3D 픽사 숏폼**

## 순서 (절대 순서 고정)

1. 링크를 받으면 스크립트 실행:
   ```bash
   bash .claude/skills/reels-reader/reels_read.sh "<링크>"
   ```
   - yt-dlp로 영상 다운로드 → faster-whisper(small, 한국어)로 받아쓰기 → ffmpeg로 장면 전환마다 사진 1장.
   - 출력 마지막 줄의 `OUT=` 폴더에 `transcript.txt`, `scene_times.txt`, `frames/scene_###.jpg`, `video.info.json` 생성.
2. `transcript.txt`를 읽는다.
3. `frames/` 사진을 **전부 Read 도구로 직접 본다** (상상으로 쓰지 말 것). 15장 넘으면 고르게 15장만.
   `scene_times.txt`의 n번째 줄 = scene_00n.jpg의 시각(초).
4. 아래 형식으로 정리 (전부 마크다운 코드 블록 = 복사 카드):

```
📌 원본 요약 3줄
1.
2.
3.

🎬 장면별 내용
| 시간 | 화면 | 말 |
|---|---|---|
| 0:00 | | |

💡 리치온·에이로그원에 바꿔 쓸 아이디어 3개
1. (리치온 상품 소개용) — 후킹 첫 3초 / 상품 후보(3대 방어 룰: 안 깨지고·안 썩고·안 입어보는)
2. (에이로그원 3D 픽사 숏폼용) — 시작 6초 / 전개 6초 / 완성 6초
3. (멀티유즈: 카드뉴스·블로그·리틀리)
```

5. 추가로 "첫 3초 후킹 구조"를 한 줄로 뽑아준다 (화면에 뭐가 나왔고, 첫 말이 뭐였는지).

## 다운로드가 막히면 (`DOWNLOAD_FAILED` / login required)

로아에게 쉽게 안내:
1. 크롬에 확장프로그램 **Get cookies.txt LOCALLY [겟 쿠키즈 로컬리] = 로그인 정보를 파일로 저장하는 도구** 설치
2. **내 인스타 계정이 아닌 연습용(부계정)** 으로 instagram.com 로그인 → 확장 아이콘 → Export
3. 받은 `cookies.txt`를 `.claude/skills/reels-reader/` 폴더에 넣고 다시 "릴스 읽어줘"
   - ⚠️ cookies.txt는 **절대 깃허브에 올리지 않는다** (.gitignore 처리됨). 누구에게도 보내지 않는다.
4. 클라우드 세션에서 계속 막히면: 영상 파일(mp4)을 직접 올려주면 그 파일로 2~4단계 진행
   (`reels_read.sh` 대신 파일 경로로 받아쓰기·장면 추출만 실행).

## 지킬 것

- 남의 릴스는 **공부용** — 구조만 배우고, 영상·대본을 그대로 다시 올리지 않는다.
- 모든 도구 무료(로컬 실행). 크레딧 드는 도구(vidIQ 등)는 이 스킬에서 쓰지 않는다.
- 작업 끝나면 `OUT` 폴더(영상 파일)는 지워도 됨 — 레포에 영상 커밋 금지.
