# 제품명만으로 자료 찾기 (검색 순서)

로아님이 제품명만 줘도 아래 순서로 웹 검색해서 `product-info.md`를 직접 만든다.
모든 줄 끝에 출처를 적는다. 출처 없는 내용은 페이지에 쓰지 않는다.

## 1. 검색 순서 (한 번에 여러 검색을 같이 보낸다)
| 순서 | 무엇을 | 어디서 | 검색어 예 |
|---|---|---|---|
| ① | 공식 설명·핵심 성분·함량·특징 | 브랜드 공식몰 제품 소개 | `{제품명}`, `{브랜드} 공식` |
| ② | 상품정보제공고시(용량·제조업자·사용기한·전성분·주의사항·상담번호) | 네이버 **브랜드 공식스토어**(brand.naver.com) → 홈쇼핑·컬리 고시 | `{제품명} 상품정보제공고시`, `{제품명} 제조업자` |
| ③ | 판매량·재구매율·수상 등 숫자 | 언론 기사(약업신문 등 전문지) | `{브랜드} 누적 판매`, `{제품명} 재구매율` |
| ④ | 단점·주의(honest 섹션) | 컬리 "구입 전 참고사항", 공식스토어 Q&A, 리뷰 요약 | `{제품명} 향`, `{제품명} 단점` |
| ⑤ | 같은 브랜드 다른 라인 비교(compare 섹션) | 공식몰 목록, 비교 정리글 | `{브랜드} {제품군} 차이` |
| ⑥ | 가격 최저·최고(price 섹션) | 공식몰 판매가·소비자가, 네이버 공식스토어, 11번가·G마켓·쿠팡, 다나와 | `{제품명} 가격`, `{제품명} 최저가` |

참고 링크(블로그 등)를 받았으면 그 글은 **흐름만** 참고한다(문장·사진 사용 금지).

## 2. 정보가 서로 다를 때
1. 네이버 브랜드 공식스토어의 **같은 용량 단품** 표기
2. 브랜드 공식몰
3. 대형 판매처 고시(홈쇼핑·컬리)
4. 그래도 다르면 페이지에 `[확인 필요]`, open-items.md에 두 값을 같이 적는다

## 3. 가격 정리 규칙
- 단품 1개(같은 용량) 기준으로만 비교한다. 세트·증정 구성은 뺀다.
- 표 4줄: 최저(판매처 이름·배송비) / 공식 최저 / 공식몰 / 최고(정가=소비자가)
- 막대 위치: `left% = (가격 − 시작값) ÷ (끝값 − 시작값) × 100`. 시작·끝은 최저·최고를 감싸는 만 원 단위.
- 기준 시점(연·월)을 note에 적는다. 1개 판매처에만 있는 비정상적인 최저가(정가의 40% 미만)는 빼고 open-items.md에 남긴다.

## 4. 사진
- 로아님이 준 사진만 쓴다. 인터넷에서 상품 사진을 내려받아 쓰지 않는다.
- 사진이 없으면: 1장만 달라고 한 번 요청하고, 그동안 글·표 중심으로 만든다(사진 자리는 `.ph` 빈칸).
