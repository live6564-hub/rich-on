# 잘 팔리는 상세페이지 섹션 사전

국내 스마트스토어·쿠팡·자사몰 상위 상세페이지에서 반복되는 흐름을 정리한 것이다.
참고 페이지를 찾지 못했을 때 기본값으로 쓰고, 찾았으면 그 흐름을 우선한다.
**구조만 참고한다. 문장·이미지·로고는 가져오지 않는다.**

## 1. 섹션 사전 (data-section 이름 → 역할)

| 이름 | 역할 | 제목 모양 예시 | 필요한 입력 |
|---|---|---|---|
| hero | 첫 화면. 3초 안에 "나한테 필요한 것" 각인 | "당김은 빼고 촉촉함만" / "아침 5분, 도시락 끝" | 대표 사진 1장, 핵심 한 줄 |
| pain | 고민 공감 체크리스트 | "이런 적 있으시죠?" | 타깃의 불편 3~4개 |
| solution | 상품 등장, 한 문장 정의 | "그래서, ○○" | 상품명·한 줄 정의 |
| point-1~3 | 핵심 장점 3개(번호 크게) | "POINT 01 / 하루 종일 촉촉" | 장점별 근거·사진 |
| proof | 수치·시험·인증 | "숫자로 확인하세요" | **실제 자료만** |
| how-to | 사용법 3단계 | "이렇게 쓰세요" | 단계·사용 컷 |
| scene | 활용 장면(어디서·언제) | "이럴 때 꺼내 보세요" | 장면 사진 2~4장 |
| review | 구매 후기 | "먼저 써 본 분들" | **실제 후기만** |
| compare | 일반 제품 vs 이 제품 | "뭐가 다를까?" | 비교 기준(사실만) |
| option | 구성·옵션·용량 | "구성을 확인하세요" | 옵션표 |
| spec | 상품 정보 고시 | "상품 정보" | 용량·원산지·제조사 등 |
| faq | 자주 묻는 질문 3~5개 | "자주 묻는 질문" | Q&A |
| cta | 마무리·구매 유도·고지 | "지금, 촉촉함부터" | 가격(있으면)·링크 |

## 2. 카테고리별 기본 흐름

- **화장품·스킨케어**: hero → pain → solution → point-1~3 → proof(성분·테스트) → how-to → review → spec → faq → cta
- **식품·간편식**: hero(시즐컷) → solution → point-1~3(맛·원재료·간편) → how-to(조리법) → scene → review → spec(영양·알레르기) → cta
- **생활용품·주방**: hero → pain → solution → point-1~3 → compare → how-to → scene → option → spec → faq → cta
- **가전·도구**: hero → pain → solution → point-1~3 → proof(스펙 수치) → how-to → compare → option → spec(전기·AS) → faq → cta
- **패션잡화(가방·소품)**: hero → scene → point-1~3(소재·수납·디테일) → option(색상) → spec(사이즈) → faq → cta

## 3. 제목 규칙

1. 한 줄 12자 안팎, 최대 2줄. 줄바꿈 위치를 직접 정한다(`<br>`).
2. 다섯 가지 틀 중 하나: **대비**("A는 빼고 B만") / **숫자**("3초면 끝") / **질문**("아직도 ○○하세요?") /
   **장면**("퇴근 후 10분 저녁") / **선언**("이제, ○○ 하나로").
3. 영어 라벨(POINT 01, HOW TO USE)은 작게, 한글 제목은 크게.
4. 같은 틀을 3번 연속 쓰지 않는다.

## 4. 리듬 규칙 (모바일 스크롤)

- 사진 섹션과 글 섹션을 번갈아 놓는다. 글만 2섹션 연속 금지.
- 배경색 교대: 흰색 → `--brand-soft` → 흰색 … (hero·cta는 사진/진한 색).
- 섹션 하나는 860px 기준 높이 900~1800px 안쪽 → 자를 때 한 장에 한 섹션이 들어간다.
