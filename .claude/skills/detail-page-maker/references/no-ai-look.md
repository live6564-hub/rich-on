# AI 티 안 나는 상세페이지 규칙 (2026-11 세포랩 작업에서 확정)

기준 결과물: `detail-pages/cepolab-biogenic-essence/out/v02/` (리치온 저장소)

## 1. 디자인
| 하지 말 것 (AI 티) | 대신 할 것 |
|---|---|
| 모든 글을 가운데 정렬한 카드 나열 | 왼쪽 정렬 + 가는 선(1px) + 여백 |
| 보라·파랑 그라데이션, 네온, 빛 번짐 | 상품 사진에서 뽑은 색 1개 + 종이색(#F6F1E8) + 먹색(#221C15) |
| 둥근 카드 + 그림자 남발 | 표·줄 노트·번호 목록 (잡지 레이아웃) |
| 이모지·체크 아이콘·별점 그림 | 명조 숫자(①, 01), 작은 영문 라벨 + 짧은 선 |
| 모든 제목 같은 굵기의 고딕 | 제목은 명조(Noto Serif KR), 본문은 고딕(Noto Sans KR) |
| 사진을 억지로 꽉 채워 흐리게 | 흰 배경 사진은 흰 섹션에 그대로, 크기는 선명한 만큼만 |
| AI로 만든 가짜 연출컷 | 실제 사진만. 없으면 섹션을 글·숫자·표로 구성 |

## 2. 문장
- 말투: 친구에게 설명하는 존댓말("~예요", "~하세요"). 감탄사·느낌표 연발 금지.
- 금지 단어: 혁신적, 놀라운, 완벽한, 압도적, 최고의, 획기적, 마법 같은, 기적, 100%, 완치, 치료, 지금 바로!, 단 하나의
- 추상어 대신 장면: "건조함 고민" ❌ → "수건 내려놓기도 전에 볼이 땅긴다" ⭕
- 숫자는 **반드시 출처 각주**(`<p class="note">출처 · …</p>`)와 기준 시점을 단다.
- 이름 속 숫자·용어의 **진짜 뜻**을 풀어 준다(예: "90%는 수분이 아니라 원료 함량").
- 단점을 먼저 말하는 `honest` 섹션 필수: 판매처 "구입 전 참고사항"·Q&A·리뷰의 실제 불만(향, 색, 용량, 배송 등).
- 리치온이 소개자임을 숨기지 않는다: cta 고지문에 "브랜드 공식 페이지가 아닌 리치온의 소개 페이지예요."

## 3. 정보 신뢰
- 지어낸 후기·별점·판매량·가격 0개.
- 판매처마다 다른 정보(제조업자·사용기한)는 **공식 스토어 표기**를 쓴다.
- 가격은 최저·최고를 같이 보여 주고, 최저가가 공식 판매처가 아니면 정품 확인 안내를 단다.
