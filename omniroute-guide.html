  1. 시작 버튼 → PowerShell 입력 → 엔터
  2. 아래를 붙여넣고 엔터
PowerShell 창
버전 확인node -v
나온 결과할 일

2PowerShell 실행 허용

윈도우는 처음에 설치 명령을 막아 둬요. 내 계정에서만 풀어 줄게요. 관리자 권한은 필요 없어요.

PowerShell 창
실행 허용Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
  • 질문이 나오면 Y → 엔터
  • 아무 글자 없이 PS C:\Users\...>만 다시 나와도 성공이에요
💡 이 단계를 안 하면 다음 단계에서 빨간 글씨로 "이 시스템에서 스크립트를 실행할 수 없으므로…"가 나와요.

4안전 잠금 파일 만들기

이 한 번으로 세 가지가 해결돼요.

  • 🔒 내 컴퓨터에서만 옴니라우트를 쓸 수 있게 잠그기 (같은 와이파이의 다른 사람 차단)
  • 🔑 옴니라우트 키가 있어야만 들어올 수 있게 하기
  • 🧰 윈도우판 버그 해결 — 데이터와 암호 열쇠가 다른 폴더에 떨어지는 문제를 한 폴더로 모으기

옴니라우트가 꺼진 상태에서, 아래 전체를 복사 → 붙여넣기 → 엔터. 고칠 곳은 없어요.

5대시보드 로그인 · 비밀번호 바꾸기

브라우저

대시보드 주소http://localhost:20128
  1. 처음 비밀번호는 (대문자 그대로) CHANGEME
  2. 로그인되면 Ctrl+K → 보안 입력 → "보안" 화면 열기
  3. 현재 비밀번호 CHANGEME → 새 비밀번호(8자 이상) 두 번 → [비밀번호 업데이트]

  5. 2단계 인증은 [활성화] 누르지 않기 — "비활성화됨" 그대로 (이미 내 컴퓨터만 들어올 수 있게 잠가 둬서 필요 없어요)

9옴니라우트 키 만들어 파일에 저장

클로드 코드가 옴니라우트에 들어올 때 쓰는 열쇠예요. 파일에 한 번 저장해 두면 아이콘이 알아서 꺼내 써요.

① 명령어 먼저 붙여 두기 (엔터 ❌)

옴니라우트 창 말고 PowerShell 창을 하나 더 열어요. 아래 줄을 붙여넣고 엔터는 아직 누르지 않기!

새 PowerShell 창
키 파일 저장 (끝이 -Value: 로 끝나요)Set-Content -Path $HOME\.omni-key.txt -Encoding ASCII -Value:

② 대시보드에서 키 만들기

브라우저 (대시보드)
  1. Ctrl+K → API 키 → [+ API 키 생성]
  2. 이름 클로드코드 → [만들기]
  3. sk-... 옆 📋 클릭 (v3.8.53은 oma_가 아니라 sk-로 시작해요. 정상!)
⚠️ 이 키는 창을 닫으면 다시 볼 수 없어요. 바로 ③으로!

③ 키 붙이고 엔터

PowerShell 창 클릭 → Ctrl+V → 줄 끝 -Value: 바로 뒤에 키가 붙었는지 확인 → 엔터

이렇게 보이면 엔터 (예시)Set-Content -Path $HOME\.omni-key.txt -Encoding ASCII -Value:sk-xxxxxxxxxxxx

④ 확인

키 앞 3글자만 보기(Get-Content $HOME\.omni-key.txt).Substring(0,3)
✅ sk-가 나오면 성공! (키를 잃어버려도 ②~④를 다시 하면 새 키로 바뀌어요)

📌 기억할 규칙 5가지

  1. 명령어는 PowerShell 창(PS C:\…>)에, 질문은 클로드 코드 창(>)에
  2. 옴니라우트 창(OmniRoute is running!)은 쓰는 동안 닫지 않기
  3. 맨 아래가 manual mode인지 확인. 바뀌었으면 Shift를 누른 채 Tab을 톡 → 노란 auto 표시가 없어질 때까지
  4. 열쇠(AIza… / sk-…)와 개인정보는 보내지 않기
  5. 무료 모델은 진짜 클로드보다 실수가 많아요 → 파일 수정·실행 허락 전에 내용 읽어 보기
