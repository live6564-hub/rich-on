1. 한눈에 보기

클로드 코드 쓰다가 사용량 한도에 자주 걸리시나요? 옴니라우트는 AI 제공자 수백 곳을 주소 하나로 묶어 주는 내 컴퓨터용 무료 오픈소스 도구예요. 한 곳이 한도에 차면 연결해 둔 다른 모델로 자동으로 넘겨서 작업을 이어 가요.

항목내용
무엇여러 AI 제공자를 주소 하나(http://localhost:20128/v1)로 묶는 AI 게이트웨이
Gateway [게이트웨이] = 여러 곳으로 가는 길을 한 문으로 모아 주는 관문
연결할 수 있는 곳제공자 375~380곳 (무료 표시 153곳), 모델 1,400개 이상
핵심 기능한도·오류가 나면 다음 제공자로 자동 전환
Quota-aware auto-fallback [쿼터 어웨어 오토 폴백] = 남은 사용량을 보고 알아서 예비로 넘어가기
비용옴니라우트 자체는 무료(MIT). 각 제공자 무료 사용량은 내가 직접 가입해서 받은 만큼
같이 쓰는 도구클로드 코드, Codex, Cursor, Cline, OpenCode 등 39개
설치npm install -g omniroute 한 줄 (Node.js 22 이상 필요)
⚠️ 옴니라우트가 토큰을 공짜로 주는 게 아니에요. 공식 문서에도 "제공자마다 직접 가입하고 키를 받아 연결하라, 한도와 약관은 각 제공자가 정한다"고 적혀 있어요. 설치만 하고 아무것도 연결 안 하면 답이 안 나올 수 있어요.

2. 설치 — 명령어 한 줄

먼저 Node.js [노드 제이에스] = 자바스크립트 프로그램을 돌리는 엔진이 깔려 있어야 해요 (버전 22 이상). nodejs.org에서 LTS 버전을 받으면 돼요.

1) 설치하고 실행 (README 공식 명령)

터미널에 붙여넣기npm install -g omniroute omniroute

실행하면 브라우저에서 대시보드가 열려요: http://localhost:20128
-g (global [글로벌] = 전역)로 깔면 어느 폴더에서든 omniroute 명령을 쓸 수 있어요. 이 방법을 기본으로 쓰세요.

✅ 실제 설치 화면 예시 — npm install -g omniroute → added 1331 packages in 1m → 버전 3.8.53 (현재 최신 3.8.54)

2) 처음이라면 도우미 마법사

첫 설정 마법사 · 문제 진단omniroute setup omniroute doctor

setup = 처음 설정 안내, doctor = 제공자·포트·설치 문제 자동 진단.

3. 제공자 연결하기

  1. 대시보드(localhost:20128) → 왼쪽 Providers [프로바이더스] = 제공자 클릭
  2. + Add Provider → 아래 안전한 7곳 중 하나 선택
  3. 그 제공자 사이트에서 가입 → API Key [에이피아이 키] = 프로그램끼리 연결하는 비밀 열쇠 발급 → 붙여넣기
  4. 2~3곳 이상 연결해 두면 한 곳이 막혀도 다음 곳으로 자동 전환
  5. Dashboard → Endpoints에서 옴니라우트 전용 키를 복사해 둬요 (클로드 코드 연결에 사용)
💡 추천 첫 조합: Gemini + Groq + OpenRouter(:free) — 세 곳 다 카드 없이 키 발급 가능.

4. ✅ 안전한 7곳 연결법

기준: 카드 X · 무료 · 약관에 프록시 금지 조항 없음 · 개인 사용 OK. 걸리는 조건이 "재판매 금지"뿐인 곳까지 넣었어요. 나 혼자 쓰면 해당되지 않는 조건이에요.

2단계 · 옴니라우트에 키 넣기

  1. 대시보드 왼쪽 Providers [프로바이더스] 클릭
  2. + Add Provider → 검색창에 gemini / groq / openrouter …
  3. 복사한 키 붙여넣기 → Save → Test 눌러 초록불 확인
  4. 나머지 제공자도 똑같이 반복
  5. Endpoints [엔드포인트] → 옴니라우트 전용 키(oma_...) 복사
⚠️ OpenRouter는 이름 끝이 ":free"인 모델만 켜 두세요. 유료 모델이 켜져 있으면 요금이 나갈 수 있어요.

3단계 · 자동 전환 순서 정하기

대시보드 → Combos [콤보] = 여러 모델을 묶은 예비 순서

추천 순서1 Gemini → 2 Groq → 3 OpenRouter(:free) → 4 NVIDIA → 5 GitHub Models

모델에서 auto를 고르면 연결된 곳 중에서 알아서 골라요. 클로드 코드 연결은 아래 5번을 보세요.

4단계 · 잘 되는지 확인

  • 클로드 코드에서 "안녕" 입력 → 답이 오면 성공
  • 대시보드 → Logs [로그] = 사용 기록에서 어느 제공자로 갔는지 확인
  • 안 되면 터미널에 omniroute doctor

5. 클로드 코드 연결법

방법 A — 가장 쉬운 한 줄 (추천)

주소·키를 알아서 넣고 클로드 코드 실행omniroute launch

옴니라우트가 켜져 있는지 확인한 뒤 환경 변수를 자동으로 넣고 claude를 실행해 줘요.

방법 B — 설정 파일에 직접 넣기

맥은 ~/.claude/settings.json, 윈도우는 C:\Users\내이름\.claude\settings.json 파일에 아래를 넣고, 클로드 코드를 껐다 켜요 (설정은 시작할 때 한 번만 읽어요).

~/.claude/settings.json{ "env": { "ANTHROPIC_BASE_URL": "http://localhost:20128", "ANTHROPIC_AUTH_TOKEN": "여기에-옴니라우트-키-붙여넣기", "CLAUDE_CODE_ENABLE_GATEWAY_MODEL_DISCOVERY": "1" } }
⚠️ ANTHROPIC_BASE_URL 끝에 /v1을 붙이지 마세요. 클로드 코드가 알아서 /v1/messages를 붙여요. (Cursor·Cline 같은 다른 도구는 /v1을 붙인 주소를 써요.)

Environment variable [인바이런먼트 배리어블] = 프로그램이 시작할 때 읽어 가는 설정값

방법 C — 다른 도구 연결 (Cursor·Cline 등)

도구 설정 화면에 입력Base URL: http://localhost:20128/v1 API Key: (Dashboard → Endpoints에서 복사) Model: auto

auto = 연결해 둔 제공자 중에서 알아서 골라 보내기.

6. 공식 무료 키 제공자 14곳

제공자 공식 사이트에서 정식으로 API 키를 발급받는 곳만 골랐어요. 한도는 수시로 바뀌니 가입 전에 그 사이트에서 꼭 다시 확인하세요.

7. 약관 주의 제공자 12곳 — 피하는 게 좋아요

옴니라우트 공식 약관표(FREE_TIERS.md)에서 "프록시·제3자 도구로 쓰지 말라"는 조항이 확인된 곳이에요. 연결하면 계정 정지 위험이 있어요.
Proxy [프록시] = 중간에서 대신 요청을 전달해 주는 프로그램 (옴니라우트가 여기에 해당)

8. 자주 막히는 곳

증상해결
클로드 코드가 옴니라우트를 안 거침주소 끝 /v1 지우기 → 클로드 코드 재시작
인증 오류 (401)ANTHROPIC_AUTH_TOKEN에 옴니라우트 키 넣었는지 확인, 또는 omniroute launch 사용
400 Ambiguous modelClaude 제공자가 2개 연결됨 → ANTHROPIC_MODEL=cc/모델명처럼 앞에 이름 붙이기
auto인데 답이 안 옴제공자를 하나도 안 연결한 상태 → 4번 안전한 7곳에서 2~3곳 연결
설치 오류node -v로 22 이상인지 확인 → omniroute doctor
