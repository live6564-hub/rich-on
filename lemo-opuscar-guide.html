66가지 스타일 애니메이션 만들기

lemo-opuscar [레모 오퍼스카] 스킬 하나로 손그림·수채화·종이팝업 같은 애니메이션을, 이야기·음악·자막까지 코드로 렌더링해 영상 파일로 받는 법. 에이로그원 세로 숏폼용으로 정리했어요.

2026.11.08 · lemo-opuscar 공식 저장소 README · TECHNIQUE · MY-STYLES · AGENTS 문서 기준

먼저 알아 둘 점 3가지

⚠️ 한계 먼저 안내
  • 설치는 로아 컴퓨터에서 직접 해야 해요. 웹·앱 채팅 속 클로드는 로아 컴퓨터에 프로그램을 깔 수 없어요. 클로드 코드(터미널 또는 데스크탑 앱 Code 탭)에서 실행하세요.
  • 한국어 기본 음성이 없어요. 기본 음성 합성은 영어(Kokoro)와 중국어(edge-tts)만 있어요. 한국어는 내 녹음 파일을 넣는 방식이 가장 확실해요 (05번 참고).
  • 한 편에 30~60분 걸리고 토큰을 꽤 써요. 기본 결과물은 1920×1080 가로라서, 숏폼은 1080×1920 세로라고 꼭 적어야 해요.
💸 무료 범위 체크
  • 무료스킬 자체 — MIT [엠아이티] 라이선스 = 누구나 무료로 쓰는 공개 코드
  • 무료그림·음악·효과음 — 영상 생성 AI 없이 코드로 그려서 생성 크레딧이 0이에요
  • 무료내 휴대폰 녹음으로 한국어 나레이션
  • 유료클로드 코드 — 클로드 유료 요금제(Pro 이상) 사용량 안에서 토큰 소모
  • 크레딧피쉬오디오 로아 목소리 — 쓰려면 실행 전 잔액·예상 크레딧 확인 후 로아 허락 필수
✅ 내 영상은 내 것

이 스킬로 만든 영상은 로아 소유예요. 출처 표기 필요 없고 워터마크도 없어요. 단, 공식 갤러리 데모 영상을 가져다 쓸 땐 CC BY 4.0 [씨씨 바이] = 출처(LemoLab)만 밝히면 상업 이용 가능한 라이선스 규칙을 지켜야 해요.

STEP 01

준비물 확인하기

lemo-opuscar는 클로드가 코드로 화면을 그리고, 한 프레임씩 찍어서 소리와 합치는 방식이에요. 그래서 내 컴퓨터에 아래 도구가 있어야 해요. 나머지 패키지는 클로드가 알아서 설치해요.

도구버전하는 일
클로드 코드유료 요금제스킬을 실행하는 곳
Node.js [노드제이에스]20 이상화면을 그려 프레임으로 찍기
ffmpeg [에프에프엠펙]7 이상프레임 + 소리 → 영상 파일로 합치기
Python [파이썬]3.11 이상 (또는 uv)음악·음성 합성, 소리 섞기

터미널 [= 글자로 명령을 내리는 검은 창]에 아래 세 줄을 넣으면 지금 버전이 나와요.

버전 확인
node -v
ffmpeg -version
python3 --version
ffmpeg는 꼭 7 이상

6.x 버전은 소리 길이를 짧게 잡아서 마지막 합치기 단계(mux.sh)에서 “소리가 잘렸다”며 멈춰요. 우분투 24.04 기본 ffmpeg가 6.1이라 이 경우 공식 문서가 안내하는 static build [스태틱 빌드] = 설치 없이 바로 쓰는 완성본 파일을 받으세요.

공식 개발 환경은 macOS [맥오에스]예요. Windows [윈도우]는 WSL [더블유에스엘] = 윈도우 안에서 리눅스를 돌리는 기능에서 쓰라고 안내해요. 3D·셰이더가 많은 스타일은 그래픽카드가 있으면 빨라요.

STEP 02

스킬 설치하기

클로드 코드가 깔린 터미널에서 두 줄을 차례로 실행하세요. 첫 줄은 플러그인 마켓에 저장소를 추가하고, 둘째 줄이 설치해요.

설치 명령어
claude plugin marketplace add lemomo-ai/lemo-opuscar
claude plugin install lemo-opuscar@lemolab
  • 설치 후엔 어느 폴더에서든 쓸 수 있어요.
  • 처음 영상을 만들 때 스타일 설명서·도구가 ~/lemo-opuscar 폴더로 내려받아져요.
  • 영상마다 만드는 파일은 클로드 코드를 시작한 폴더에 생겨요 → 바탕화면에 에이로그원-애니 폴더를 만들고 거기서 시작하면 정리가 편해요.
💡 이렇게 하면 안 막혀요

저장소 주소만 주고 “이거 설치해 줘”라고 하면 클로드가 저장소 안 설치 스크립트 실행을 거부할 수 있어요. 위 두 줄로 플러그인부터 설치하고 바로 영상을 주문하세요.

STEP 03

첫 애니메이션 주문하기

스타일 이름은 영어 이름 그대로 넣으세요. < > 안만 바꿔서 붙여넣으면 돼요. 숏폼용 세로 조건을 미리 넣어 둔 리치온 버전이에요.

첫 주문 (세로 숏폼)
<Watercolor Brush> 스타일로 <새벽 5시, 동네 빵집이 문을 여는 이야기>를 <30>초 영상으로 만들어 줘.
- 크기: 1080×1920 세로 (인스타 릴스·유튜브 쇼츠용)
- 자막: 한국어
- 나레이션: 없이 음악과 효과음만 (나레이션은 다음 편에서 내 녹음으로 넣을게)
- 스토리보드를 먼저 보여 줘

스타일을 아직 못 정했다면 스킬 이름만 입력하세요. 언어를 묻고 → 무엇을 할지(갤러리 스타일로 영상 / 갤러리 스타일을 바꿔 내 스타일 / 빈 페이지에서 내 스타일) 고르게 해요.

메뉴로 시작
/lemo-opuscar:lemo-opuscar

주문하면 클로드가 처음에 한 번 몰아서 물어봐요

  1. 주제에서 스스로 정할 수 없는 부분
  2. 내 목소리·음악·사진·로고 같은 자료가 있는지
  3. 스토리보드를 먼저 볼지 → “예” 추천. 실제 스타일로 그린 주요 장면을 한 번 보여 주고 멈춰서, 토큰 낭비 없이 방향을 잡을 수 있어요.

그다음 이야기 → 음악 → 화면 렌더링 → 소리 믹싱 → 영상 파일 순서로 자동 진행돼요.

STEP 05

한국어 나레이션 넣기

기본 음성 합성(TTS [티티에스] = 글자를 목소리로 읽어 주는 기술)은 영어·중국어만 있어요. 공식 문서도 “사용자가 녹음 파일이나 목소리를 가져오면 그걸 쓴다”고 되어 있어서, 한국어는 내 녹음 파일이 정답이에요.

무료로 녹음하는 순서

  1. 클로드에게 대본만 먼저 받아요 (아래 1번 카드).
  2. 휴대폰 음성 녹음 앱으로 한 문장 = 한 파일로 녹음해요. 조용한 방, 휴대폰은 입에서 한 뼘.
  3. 파일 이름을 01.m4a, 02.m4a …처럼 순서대로 바꿔 영상 폴더 안 voice 폴더에 넣어요.
  4. 아래 2번 카드로 영상을 주문해요.
1. 대본 먼저 받기
<Whiteboard Explainer> 스타일로 <수세미를 일주일마다 바꿔야 하는 이유> 30초 세로 영상을 만들 거야.
영상은 아직 만들지 말고, 내가 직접 녹음할 한국어 나레이션 대본만 먼저 써 줘.
- 한 문장씩 번호를 붙여서
- 한 문장은 2~4초 안에 읽을 수 있게 짧게
- 30대 주부 말투, 친근하게
2. 내 녹음으로 영상 만들기
방금 대본으로 영상을 만들어 줘.
- 나레이션: 기본 음성 합성 대신 voice 폴더의 내 녹음 파일(01~번 순서)을 사용
- 화면 전환과 자막 타이밍을 내 녹음 길이에 맞춰 줘
- 자막: 한국어, 대본 그대로
- 크기: 1080×1920 세로
- 목소리는 음악보다 또렷하게
⛔ 하면 안 되는 것

공식 데모 중 6편(Chalkboard, Circuit Board, Desktop Flythrough, Isometric Picture Book, Printed Long Take, Broadcast News Package)의 나레이션은 재사용 금지예요. 내 영상에는 내 목소리나 사용 권한이 있는 목소리만 쓰세요.

피쉬오디오 로아 목소리를 쓰고 싶다면

크레딧이 드는 기능이라, 실행 전에 남은 크레딧과 예상 크레딧을 먼저 확인하고 로아가 허락한 뒤에만 생성해요. 무료로 끝내려면 휴대폰 녹음이 가장 좋아요.

STEP 06

리치온 전용 스타일 만들기

갤러리 스타일을 고쳐서, 또는 빈 페이지에서 내 브랜드 색·로고·캐릭터를 넣은 나만의 스타일을 만들 수 있어요. 이미지 생성 AI 없이 전부 코드로 그려요.

시작하는 두 가지 방법

  • 갤러리 스타일 고치기 — 전체 목록을 보여 주면 고칠 스타일 이름을 입력해요.
  • 빈 페이지에서 — 원하는 느낌을 말로, 또는 좋아하는 사진·영상을 보여 주면 가장 가까운 갤러리 스타일을 바탕으로 골라 줘요.

그다음 5단계

  1. 한 번에 하나씩 질문 — 용도·플랫폼(세로 숏폼은 1080×1920 또는 1080×1440)·브랜드 색·로고·폰트·캐릭터. 갤러리 스타일은 “바꿔도 안전한 것 / 성격이 바뀌는 것 / 못 바꾸는 것”으로 나눠 보여 줘요. 한 번에 최대 5가지 변경.
  2. 요약 확인 — 바뀌기 전·후와 비용을 보여 주고, 동의하기 전엔 아무것도 저장 안 해요.
  3. 스타일 프레임 1장 — 원본(왼쪽)과 내 버전(오른쪽)을 나란히 보여 줘요.
  4. 15~30초 데모 영상 — 음악·효과음 포함, 한 번 자체 점검 후 전달.
  5. 저장 — “내 스타일로 저장 / 한 번 더 / 지금은 안 함” 중 선택. 저장하면 ~/lemo-my-styles/에 보관되고 업데이트·삭제해도 안 지워져요.
리치온 브랜드 스타일 만들기
<Paper Pop-up Book> 스타일을 내 브랜드 스타일로 바꾸고 싶어.
- 용도: 살림·생활용품 소개 숏폼 (인스타 릴스, 유튜브 쇼츠)
- 크기: 1080×1920 세로
- 브랜드 색: 네이비 #1A2038 바탕, 골드 #D4AF37 포인트
- 폰트: 한국어가 들어가는 무료 폰트 (예: Pretendard)
- 로고: 지금은 없음, 마지막 장면에 "리치온" 글자만
- 느낌: 고급스럽지만 따뜻하게
스타일 이름은 "Rich-On Pop-up"으로 해 줘.

저장 후엔 이렇게 불러요: “내 Rich-On Pop-up 스타일로 <주제> 30초 세로 영상 만들어 줘.” 스타일을 고를 때 내 스타일이 맨 위에 나와요.

전체 진행 프롬프트
나는 클로드 코드로 lemo-opuscar 스킬을 써서 숏폼 애니메이션을 만들고 싶어. 아래 순서대로 한 단계씩 같이 진행해 줘. 각 단계가 끝나면 나한테 확인받고 다음으로 넘어가.

1. 준비물 점검: node -v, ffmpeg -version, python3 --version 을 실행해서 Node 20+, ffmpeg 7+, Python 3.11+ 인지 확인하고, 부족한 게 있으면 내 운영체제에 맞는 설치 방법을 알려 줘.
2. 설치: claude plugin marketplace add lemomo-ai/lemo-opuscar 와 claude plugin install lemo-opuscar@lemolab 를 안내해 줘.
3. 스타일 추천: 66개 스타일 중 살림 꿀팁·생활용품 소개에 맞는 스타일 3개를 이유와 함께 추천해 줘.
4. 첫 영상: 내가 고른 스타일로 30초, 1080×1920 세로, 한국어 자막, 스토리보드 먼저 보여 주기.
5. 한국어 나레이션: 기본 음성은 영어·중국어만 있으니, 내가 녹음할 대본을 문장별 번호로 먼저 주고, 녹음 파일을 받으면 그 길이에 맞춰 영상을 만들어 줘.

규칙: 크레딧이나 결제가 생길 수 있는 도구는 실행 전에 멈추고 나한테 먼저 물어봐. 영어 용어는 "영어 [한글 발음] = 뜻" 형태로 설명해 줘.
