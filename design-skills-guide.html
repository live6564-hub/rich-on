RICH-ON 작업 가이드

디자인 스킬 하나로
달라지는 페이지

클로드로 상세페이지·홈페이지를 만들 때 쓰는 디자인 스킬 2종 설치법과, 올리기 전 꼭 돌릴 '지어낸 내용' 확인 문장을 정리했습니다.

왜 필요한가

스킬 없이 만들면 비슷한 모양이 반복되고, 알려 준 적 없는 고객 후기·성과 숫자·요금이 들어갈 때가 있습니다. 플로우랩이 같은 요청을 세 번 넣어 비교한 결과(2026.10.29), 스킬 없는 결과에는 지어낸 후기 3개와 성과 숫자가 들어갔고, 두 스킬도 요금표·무료 조건은 지어 넣었습니다.

→ 어떤 방법으로 만들든 마지막 확인 문장은 필수입니다.

두 스킬 비교

앤트로픽 공식

frontend-design

업종·손님부터 따져서 콘셉트를 잡아 줌. 예: 글쓰기 서비스 → 원고지 콘셉트.

추천 상황: 상품마다 개성 있는 콘셉트가 필요할 때 · 약 15분

에밀 코왈스키 · MIT 공개

apple-design

흰 여백, 큰 제목, 부드러운 움직임. 다크모드·움직임 줄이기 설정까지 대응.

추천 상황: 군더더기 없는 고급 무드가 필요할 때 · 약 25분

설치

① frontend-design — 클로드 코드 입력창에 보내기 (Plugin [플러그인] = 추가 기능)

/plugin install frontend-design@claude-plugins-official

이미 깔려 있는데 꺼져 있을 수 있어요. /plugin 에서 켜져 있는지 확인.

② apple-design — 터미널 (Terminal [터미널] = 명령을 글자로 넣는 창)에서 실행. 끝에 -g 붙이면 모든 폴더에서 사용.

npx skills@latest add emilkowalski/skills --skill apple-design

✅ 이 저장소(rich-on)에는 이미 설치해 두었습니다 → .claude/skills/apple-design

처음부터 이렇게 요청

괄호 안만 바꿔 쓰세요. 지어내지 말라고 미리 못 박는 문장입니다.

/apple-design 리치온 상품 소개 페이지를 만들어 줘. 상품 이름은 (상품명), 특징은 (내가 확인한 사실 3가지), 주로 찾아오는 손님은 30대 주부야. 내가 알려 준 내용만 쓰고, 고객 후기·별점·판매 순위·수상·성과 숫자·가격은 지어내지 말고 비워 둬. 파트너스 링크 4개와 파트너스 수수료 고지 문구를 넣고, index.html 한 파일로 만들어 줘.

frontend-design으로 만들 때는 맨 앞 /apple-design 을 지우고 'frontend-design 스킬을 써서' 를 넣으면 됩니다.

다 만든 뒤 꼭 확인할 것

같은 채팅창에서 이어서 보내세요.

이 페이지에서 내가 알려 주지 않은 숫자, 고객 후기, 별점, 판매 순위(1위·베스트셀러), 사람·회사 이름, 요금·할인율, 무료 조건, 수상·인증(FDA·KC 등), "직접 사용" 체험담을 전부 찾아서 표로 보여 줘. 내가 알려 주지 않은 것은 지우거나 [확인 필요]로 바꿔 줘.
리치온 특히 주의
  • 별점·평점 숫자 → 출처 사이트 + 날짜 없으면 삭제
  • "1위", "Best-Seller" → 조사 기관·기간 없으면 "인기", "리치온 Pick"
  • "직접 사용한 후기" → 실제로 써 본 상품만
  • "FDA 승인" → 텀블러·용기는 "FDA 식품접촉 기준 적합"
저장소 전체 점검 결과는 점검 보고서에 있습니다.

요금 안내

두 스킬은 무료입니다. 다만 클로드 코드는 Pro 이상 유료 요금제에서 쓸 수 있고, 만드는 동안 쓴 만큼 사용량이 줄어듭니다.
